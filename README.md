I'm a student developer from India focused on **backend engineering, scalable application architecture, APIs, databases, realtime systems, DevOps, and full-stack product development**.

- **Currently improving:** JavaScript, TypeScript, backend architecture, performance, and production engineering
- **Backend:** Node.js, Fastify, Express.js, REST APIs, WebSockets, webhooks
- **Data:** PostgreSQL, MongoDB, MySQL, Redis, Prisma, Mongoose
- **Systems:** BullMQ, queues, caching, authentication/OAuth, CLI tooling
- **Frontend:** React, HTML, CSS, Tailwind CSS, JSX, TSX
- **Mobile / Edge:** Flutter, Dart, React Native, ESP32 and sensor-based systems
- **DevOps:** Docker, Kubernetes, GitHub Actions, Vercel, Render, Cloudflare
- **Programming background:** C, C++, Java, Python, Rust
- **Development environment:** Ubuntu, Kali Linux, Termux
- **Problem solving:** DSA, LeetCode, algorithms, complexity analysis
