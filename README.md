## About Me

I'm a dedicated **student developer** from India with a strong passion for building scalable, production-grade backend systems — from scratch, so I actually understand the internals.

- **Currently improving:** JavaScript & TypeScript, with a focus on efficient, scalable backend architecture
- **Growing into:** Redis, Dart, BullMQ, WebSockets, Docker, OAuth, and CLI tooling
- **Background:** C, Java, Python — helped me understand programming fundamentals deeply
- **Databases:** MongoDB, Postgres, MySQL — solid grasp of DBMS fundamentals and design
- **ORM & ODM:** Understanding abstraction and relational mapping with databases
- **Frontend:** HTML, CSS, Tailwind — responsive, visually clean UIs
- **Dev environment:** Termux on Android — running full dev stacks on a phone
- **Projects:** All live at [my repositories tab](https://github.com/nishuR31?tab=repositories)
- **Reach me:** [nishangithub@gmail.com](mailto:nishangithub@gmail.com)
